# QROR Research Assistant

A local-first RAG assistant for QROR course PDFs, with an optional Gmail PDF importer. The Streamlit app uses Sentence Transformers for embeddings, NumPy cosine similarity for retrieval, and Ollama for local answer generation. The Gmail importer uses read-only OAuth access and saves attachments to subject-specific folders.

## 1. Install prerequisites

- Python 3.11 recommended
- [Ollama](https://ollama.com/) installed and running
- Google account that receives the QROR group messages
- Google Cloud OAuth Desktop app credentials (only if using Gmail import)

In PowerShell, from this project directory:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 2. Run the local language model

```powershell
ollama pull qwen2.5:3b
ollama run qwen2.5:3b
```

Once Ollama responds, you can exit the interactive chat. The local Ollama service should remain running.

## 3. Optional: configure Gmail PDF import

The importer requests only the Gmail read-only scope `gmail.readonly`; it does not send, delete, or modify emails.

1. Open the [Google Cloud Console](https://console.cloud.google.com/), create/select a project, and enable **Gmail API**.
2. Configure the OAuth consent screen. If the app is in Testing mode, add your Google account as a test user.
3. Create an OAuth client ID with application type **Desktop app**.
4. Download the OAuth client JSON and place it in this project directory as `credentials.json`.
5. Run a preview first:

   ```powershell
   python gmail_importer.py --dry-run
   ```

6. If the messages and subject assignments look correct, import them:

   ```powershell
   python gmail_importer.py
   ```

The first run opens a browser for Google sign-in and consent. A local `token.json` is then created for subsequent runs. Keep both JSON files private; they are excluded by `.gitignore`.

### Gmail search query

Default query:

```text
has:attachment filename:pdf {to:qror26_28@googlegroups.com list:qror26_28.googlegroups.com}
```

Gmail group delivery headers vary. If the dry run finds no emails, try a broader query:

```powershell
python gmail_importer.py --dry-run --query "has:attachment filename:pdf"
```

You can set a query for repeated runs with the `GMAIL_QUERY` environment variable. `--max-results 100` is the default maximum number of messages to inspect per run; adjust it explicitly if needed.

### Classification behaviour

- Known sender addresses are mapped to the corresponding subject folder first.
- Otherwise, email subject, filename, email body, and extractable PDF text are scored against subject-specific keywords.
- The importer always selects the highest-scoring subject, as requested. If no evidence exists, it uses a deterministic fallback and marks confidence very low. **Review low-confidence assignments**, especially when using broad Gmail searches.
- Each unique PDF is deduplicated by SHA-256. The SQLite audit log stores sender, message ID, original filename, selected subject, confidence, evidence, destination, and import time.
- A scanned PDF may have no extractable text; sender and email metadata can still classify it.

The sender map and keyword lists are at the top of `gmail_importer.py`. Update them if the real sender addresses or course terminology differ.

## 4. Run the RAG app

Add PDFs manually or import them with `gmail_importer.py`. Then run:

```powershell
python -m streamlit run app.py
```

In the sidebar, click **Build / refresh index** after adding or changing PDFs. The app indexes PDFs recursively under `data/documents/`, including all five subject folders.

## How the RAG app works

1. Extracts PDF text page by page.
2. Splits text into overlapping chunks with source filename and page metadata.
3. Embeds chunks with `sentence-transformers/all-MiniLM-L6-v2`.
4. Retrieves the four closest chunks by cosine similarity.
5. Sends the question and retrieved passages to Ollama, requesting citations such as `[S1]`.

## Optional: automate the import

After testing the query and classifications manually, use Windows Task Scheduler to run `python.exe` with argument `gmail_importer.py` from this project directory on a schedule. Use the Python executable inside `.venv` if you created the virtual environment. Refresh the RAG index in Streamlit after imports; automatic index refresh is not wired into the importer yet.

## Limitations and safety notes

- The Gmail query depends on the headers Gmail exposes for group-delivered messages; test with `--dry-run` before importing.
- Keyword classification is a practical baseline, not a perfect classifier. The audit log makes decisions reviewable; verify low-confidence files.
- PDF text extraction may struggle with equations, tables, multi-column layouts, and scanned/image-only PDFs.
- Similarity scores are not probabilities. Verify important answers against the displayed source passages.
- Local inference reduces the need to send course PDFs/prompts to an external LLM API, but local execution does not by itself guarantee device security.
